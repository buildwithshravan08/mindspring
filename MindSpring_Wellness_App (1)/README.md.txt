# AI-Powered Attention Enhancement and Cognitive Wellness System

## 1. Project Overview
The AI-Powered Attention Enhancement and Cognitive Wellness System is a student-focused web application designed to improve attention, emotional well-being, and cognitive wellness through short, interactive activities and personalized recommendations.

## 2. Objectives
- Improve attention and concentration.
- Encourage healthy emotional habits.
- Provide short mood-based wellness activities.
- Promote stress management and cognitive wellness.
- Encourage consistent engagement through gamification.

## 3. Key Features
- Mood Selection: Users can select their current mood.
- Wellness Assessment: A questionnaire-based wellness score.
- Personalized Recommendations: Activities based on mood and assessment results.
- Interactive Activities: Short breathing and cognitive exercises.
- Progress Dashboard: Track wellness scores and engagement.
- Gamification: Encourage healthy habits through engagement mechanisms.

## 4. Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: SQLite
- Recommendation Engine: Rule-Based Recommendation System

## 5. Project Architecture
User Interface → Flask Backend → Rule-Based Recommendation Engine → SQLite Database → Results and Recommendations

## 6. Installation and Setup
1. Clone or download this repository.
2. Install the required Python dependencies.
3. Run the Flask application.
4. Open the local application URL in your browser.

Example:
```bash
pip install -r requirements.txt
python app.py
```

Note: Adjust the commands according to the actual project structure.

## 7. Project Purpose
This project aims to promote healthier attention habits and cognitive wellness among students through accessible, interactive, and non-diagnostic digital support.

This application is intended for educational and general wellness purposes. It is not a substitute for professional medical or mental health advice.
